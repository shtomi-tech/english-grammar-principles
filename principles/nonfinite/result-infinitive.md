# 結果を表すto不定詞(woke up to find / only to find)

## 原則

`to不定詞` は、主節の動作の後に実際に起きたことを表す「結果」の副詞的用法を持つ。この用法では、`to不定詞` の内容は主節の動作より後に起こり、主節の動作の目的ではない。`only + to不定詞` は、期待に反する結果・残念な結果を表す。

## 判断条件

- `to不定詞` の内容が、主節の動作より **後** に起きた事実かどうかを確認する。後に起きた事実なら結果、これから目指すことなら[目的](./infinitive-purpose.md)。
- 主節が `wake up`、`grow up`、`live`、`arrive`、`come` など、意図的に狙えない結末を導く動詞かどうかを確認する。
- `only to` があれば、期待に反する結果を表す合図として扱う。
- 主節と `to不定詞` を `and + 過去形` で並べても意味がほぼ変わらないかを確認する(結果用法なら変わらない)。

## 適用範囲・例外

- この用法は書き言葉・文語寄りで、`woke up to find`、`grew up to be`、`lived to be`、`only to find` のような型で現れることが多い。
- 程度・結果を表す `too ... to` / `... enough to` / `so ... as to` は別の型として、[too ... to / enough to / so ... as to](./degree-result-infinitive-patterns.md) を参照する。本カードは、そうした程度表現を伴わない無印の結果不定詞を扱う。
- `find` などが目的語の後ろに現在分詞・過去分詞を取る形は、[分詞の能動関係と受動関係](./participles-as-adjectives.md)と合わせて判断する。

## 例

- 正例: `I woke up to find myself lying on the bench.`(目を覚ましてみると、ベンチに寝ていた。)
- 正例: `She arrived home to receive a letter from her bank.`(Grammaringの用例)
- 正例: `Do you want to live to be a hundred?`(Grammaringの用例)
- 正例: `I went back to the shop only to find that it had closed for good.`(Grammaringの用例。期待に反する結果)
- 対比例: `I got up early to catch the first train.`(始発に乗るという目的。結果用法ではない)

## 誤りやすい説明

- 副詞的用法の `to不定詞` をすべて「〜するために」と目的で訳さない。結果用法では「〜して(その結果)…した」と、主節から時間順に読む。
- `only to` を「〜するためだけに」と目的で訳さない。実際に起きた、期待外れの結果を表す。
- 結果用法を、`too ... to` の否定的結果と同じものとして説明しない。前者は起きた事実、後者は程度による不成立を表す。

## 問題・解説への反映

- 正答判定では、空所の内容が主節より後に起きた事実かどうかを根拠として示す。
- 誤答選択肢には、`and + 過去形` の形で目的語や意味上の主語を落とした形、目的の用法と取り違えた形を置ける。
- 解説では、時間順(主節 → 結果)と、`and` で書き換えられることを併記する。
