# too ... to / enough to / so ... as to

## 原則

`too + 形容詞/副詞 + (for 人) + to不定詞`は「(人にとって)〜すぎて…できない」という否定的な結果を表す。`形容詞/副詞 + enough + (for 人) + to不定詞`は「…するのに十分〜だ」という肯定的な結果を表す(enoughは形容詞・副詞の後ろに置く)。`so + 形容詞/副詞 + as to不定詞`は「とても〜なので…する」という結果を表し、`so ... that ...`の書き換えに近い。

## 判断条件

- 結果が否定的(できない)か肯定的(できる)かを確認し、`too ... to`と`enough to`を区別する。
- `enough`が形容詞・副詞の前ではなく後ろに置かれているかを確認する。

## 適用範囲・例外

- `too ... to`は意味上、否定を含む(`too heavy to carry`=重すぎて運べない)。`not too ... to`にすると「〜できないほどではない」という意味になる。
- `so ... as to`はやや形式的な書き言葉で使われることが多い。
- 本カードは程度表現を伴う結果表現に限る。`woke up to find`、`only to find`のような無印の結果不定詞は[結果を表すto不定詞](./result-infinitive.md)を参照する。

## 例

- 正例: `This box is too heavy for me to carry.`
- 正例: `The bag is light enough to carry.`
- 正例: `She was so kind as to help me.`
- 対比例: `This box is enough heavy to carry.`(誤り。enoughは形容詞の後ろ)

## 誤りやすい説明

- `too ... to`を「悪いことにも良いことにも使える」と一般化しない。基本的に否定的な結果を表す。
- `enough`の語順(形容詞/副詞の後ろ)を、名詞の前に置く`enough + 名詞`の語順と混同しない。

## 問題・解説への反映

- 文脈が肯定的な結果か否定的な結果かで、`too ... to`と`... enough to`のどちらを選ぶか判断させる。
- 誤答には`enough`の語順を誤った形を含める。
