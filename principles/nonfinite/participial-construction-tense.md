# 分詞構文の時制

## 原則

分詞構文の時制は、主節との時間関係で次のように表す。

- 主節と同じ時制 → `-ing` のまま。
- 主節より1つ前 → `having + p.p.`。

## 判断条件

- 分詞構文の動作・状態が、主節と同時か、主節より前か確認する。
- 同時なら `-ing`、先行なら `having + p.p.` を選ぶ。

## 適用範囲・例外

ここでいう「同じ」「1つ前」は、主節との時間関係を捉える初学者向けの目安である。受動や進行を含む場合は、`being + p.p.` や `having been + p.p.` などの形も文全体で確認する。

## 例

- 同時: `Walking down the street, I saw Tom.`: 歩いているとき、トムを見た。
- 先行: `Having finished my homework, I went out.`: 宿題を終えてから、外出した。

## 誤りやすい説明

- 分詞構文の動作が主節より前なのに、常に単純な `-ing` だけで表すとは限らない。
- `having + p.p.` を、主節と同時の動作に使うと決めつけない。

## 問題・解説への反映

- 分詞構文の形を問う問題では、まず主節との時間関係を確認し、その後に `-ing` と `having + p.p.` を選ぶ。
- 否定や受動を含む場合は、否定形・受動態の原則と合わせて形を確認する。
