# 文頭のtoの判別

## 原則

文頭の `to` 不定詞は、次の目安で用法を判別する。

- 主語になる → 名詞的用法。
- 主語にならない → 副詞的用法。

## 判断条件

- 文頭の `to + 原形` のまとまりが、文の主語になっているか確認する。
- 主語になっていなければ、主節全体を説明する副詞的用法として確認する。

## 適用範囲・例外

このカードは、文頭に置かれた `to` 不定詞を初学者向けに判別する目安である。名詞の後ろで名詞を説明する形容詞的用法は、別カードの条件で確認する。

## 例

- `To read books is fun.`: 文頭の `To read books` が主語なので名詞的用法。
- `To save time, I took a taxi.`: `To save time` は主語ではなく、主節を説明する副詞的用法。

## 誤りやすい説明

- 文頭にあるという位置だけで、必ず名詞的用法と決めつけない。
- `to` 不定詞が主語になっているかを確認せず、訳だけで用法を決めない。

## 問題・解説への反映

- 文頭の不定詞の用法問題では、まず文の主語を特定し、`to` 不定詞が主語かどうかを説明する。
