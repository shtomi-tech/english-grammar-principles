# 相互代名詞 each other / one another

## 原則

`each other`と`one another`は「お互い」という相互の関係を表す相互代名詞で、複数の主語が互いに同じ行為をし合うことを示す。所有格は`each other's / one another's`になる。意味の近い`themselves`(再帰代名詞)は「自分自身」を表し、相互の関係ではなく各自が自分に対して行為をすることを示すため、意味が異なる。

## 判断条件

- 主語同士がお互いに行為をし合っている(相互)のか、各自が自分自身に対して行為をしている(再帰)のかを確認する。

## 適用範囲・例外

- 現代英語では`each other`と`one another`はほぼ同じ意味で使われ、「each otherは2人、one anotherは3人以上」という伝統的な使い分けは、現在では厳密な規則としては扱われない。この教材では両者の意味差を問わず、相互代名詞と再帰代名詞の違いだけを判断対象にする。

## 例

- 正例: `They blamed each other for the mistake.`(お互いを非難した=相互)
- 対比例: `They blamed themselves for the mistake.`(自分自身を責めた=再帰)
- 正例: `They respect each other's opinions.`(each other's+名詞=所有格)

## 誤りやすい説明

- 「each otherは2人、one anotherは3人以上」を、現代英語でも厳密に成り立つ規則として断定しない。
- 相互代名詞と再帰代名詞を「どちらも複数の主語で使う代名詞」とだけ説明し、意味の違い(お互いに/自分自身に)を省かない。

## 問題・解説への反映

- 選択肢に`each other`と`themselves`を並べ、文脈が相互行為か自己に対する行為かで正答を判断させる。
- `each other/one another`の使い分け(人数)を判断根拠にする問題は作らない。
