# 話法の転換に伴う時・場所を表す語の変化

## 原則

直接話法を間接話法に変えるとき、話す時点・場所を基準にした時・場所を表す語は、伝える時点・場所を基準にしても同じ内容を指すように、対応する語に置き換える。

## 判断条件

- 直接話法の中に、話す時点・場所を基準にした時・場所を表す語(`today`, `tomorrow`, `yesterday`, `now`, `here`, `this`/`these`, `ago` など)があるかを確認する。
- 伝える時点・場所が、発言した時点・場所と異なるかを確認する。異なる場合は対応する語に置き換える。

## 適用範囲・例外

- 伝える時点・場所が発言時と同じ(同じ日のうちに伝える、同じ場所で伝えるなど)で、指す内容が変わらない場合は、置き換えなくてよい。

## 対応の例

- `today` → `that day`
- `tomorrow` → `the next day` / `the following day`
- `yesterday` → `the day before`
- `now` → `then`
- `here` → `there`
- `this`/`these` → `that`/`those`
- `ago` → `before`

## 例

- 正例: `"I'm planning to do it today," she said. → She told me she was planning to do it that day.`(発言と異なる日に伝える場合)
- 対比例: 発言と同じ日のうちに伝える場合は、`today` のままでよい。

## 誤りやすい説明

- 時・場所を表す語の変化を、常に機械的に適用される規則として扱わない。伝える時点・場所との関係によっては置き換えが不要な場合がある。

## 問題・解説への反映

- 発言時点と伝達時点の時間的・場所的な関係を確認させたうえで、置き換えの要否と対応語を判断させる。
- 対応表にない語形(例: `this day`, `the day`)を選ばせる誤答選択肢は、定型の言い換えでないことを解説で示す。

## 出典・根拠

- British Council, LearnEnglish, "Reported speech: statements": 「We also change demonstratives and adverbs of time and place if they are no longer accurate. ... these changes to those, now changes to then, yesterday changes to the day before, tomorrow changes to the next/following day and ago changes to before.」 https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/reported-speech-statements （2026-07-30確認）。
