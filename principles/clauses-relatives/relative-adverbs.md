# 関係副詞 where と when

## 原則

先行詞が場所・時を表し、後ろの節に主語・目的語などがそろっていて副詞情報が欠けるとき、場所には`where`、時には`when`を使う。

## 判断条件

- 先行詞の意味と、関係詞節内で欠けている要素が名詞か副詞かを確認する。

## 適用範囲・例外

- `where = in/at which`、`when = on/at which`に相当する基本用法を扱う。

## 例

- `the town where I was born`
- `the day when we first met`

## 誤りやすい説明

- 場所の先行詞なら必ずwhereとせず、節内で主語・目的語が欠ける場合はwhich/thatを検討する。

## 問題・解説への反映

- 先行詞の種類と、後ろの節が完全か不完全かを両方示す。
