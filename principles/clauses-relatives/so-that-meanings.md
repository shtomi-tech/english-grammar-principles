# so ... that の意味

## 原則

`so + 形容詞・副詞 + that ...` は、強い程度と、その程度に結びつく内容を表す。文脈に応じて、次のように訳す。

1. 結果に焦点を置く場合は、「とても～なので、その結果…だ」となる。
2. 程度に焦点を置く場合は、「…なくらい～だ」となる。

## 判断条件

- `so` の後ろが形容詞または副詞で、その後ろに `that` 節が続いているか確認する。
- `that` 節が、強い程度から生じた結果を表しているか確認する。
- 日本語訳では、結果に焦点を置くか、程度に焦点を置くかを文脈に合わせる。

## 適用範囲・例外

ここでは、`so + 形容詞・副詞 + that ...` の結果・程度の読み方を扱う。目的を表す `so that ...` や、名詞を伴う `such ... that ...` は別の構文として区別する。

## 例

- 結果: `It was so cold that the lake froze.` — 「とても寒かったので、その結果、湖が凍った」。
- 程度: `The lake was so cold that we could not swim.` — 「私たちが泳げないくらい、湖は冷たかった」。

## 誤りやすい説明

- `so ... that` を、いつでも目的の「～するために」と訳さない。
- `so` の後ろが形容詞・副詞かどうかを確認せず、`that` があれば同じ構文だと考えない。
- 結果と程度の日本語訳の違いを、別々の形の構文だと決めつけない。

## 問題・解説への反映

- 空所問題では、`so` の後ろの品詞と `that` 節の内容をまとめて確認させる。
- 解説では、結果の読みと程度の読みを文脈に合わせて示す。
- 目的を表す `so that` と区別する問題では、目的の原則が登録された場合に併記する。
