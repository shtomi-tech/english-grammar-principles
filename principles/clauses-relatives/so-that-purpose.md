# 目的を表す so that

## 原則

`so that + S + can/could/will/would ...`は、主節の動作の目的を「～するように・～するために」と表す。

## 判断条件

- that節が主節の結果ではなく、意図された目的を表すか確認する。

## 適用範囲・例外

- `so + 形容詞・副詞 + that`の結果・程度構文とは形と意味を区別する。

## 例

- `I wrote it down so that I would not forget it.`

## 誤りやすい説明

- `so`と`that`の間に形容詞がある結果構文と混同しない。

## 問題・解説への反映

- 目的主体と助動詞を示し、結果構文との形の違いを説明する。
