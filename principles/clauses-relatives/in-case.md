# in case の意味

## 原則

`in case` は、あることが起こる場合に備える意味を表す。「もしも～の場合には」「～するといけないから」と訳せる。

## 判断条件

- `in case` の後ろに、起こる可能性のある内容が続いているか確認する。
- 主節が、その可能性に備えて先に行う行動を表しているか確認する。
- 単に条件が成立したときの結果を述べる `if` と、備えの意味を区別する。

## 適用範囲・例外

ここでは `in case + 文` の基本的な意味を扱う。主節の行動が、後ろの可能性への備えになっているかを文脈で判断する。

## 例

- `Take an umbrella in case it rains.` — 「雨が降るといけないから、傘を持っていきなさい」。
- `I wrote down the address in case I forgot it.` — 「忘れる場合に備えて、住所を書き留めた」。

## 誤りやすい説明

- `in case` を、いつでも単純な `if` と同じ「もし～ならば」とだけ説明しない。
- `in case` の後ろの出来事が起きてから行動する表現だと考えない。
- 備えを表す主節と、備えの対象になる `in case` 節の関係を確認しない。

## 問題・解説への反映

- `in case` の意味を問うときは、主節が可能性への備えになっているか確認させる。
- 解説では、「～するといけないから」「～の場合に備えて」と、備えの意味を示す。
- `if` と比較する場合は、条件の結果ではなく、事前の準備を表す点を説明する。
