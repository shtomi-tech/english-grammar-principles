# 前の節全体を先行詞にする which

## 原則

関係詞節には、名詞(句)を先行詞にするものだけでなく、前の節・文の内容全体を受けるものがある。この用法で使える関係詞は `which` であり、コンマで区切った非制限用法で用いる。

## 判断条件

- 関係詞が指しているのが、直前の1つの名詞か、それとも前の節が述べた内容全体かを確認する。
- 内容全体を受けており、それについて評価や結果を述べているなら `which` を選ぶ。
- 直前に読点(コンマ)があり、節と節をつなぐ働きをしているかを確認する。

## 適用範囲・例外

- この用法は非制限用法に限られる。制限用法(コンマなし)にはならない。
- 先行詞を含む `what`、先行詞を必要とする `that` は、この用法では使えない。
- 話し言葉では、相手の発言全体を受けて `Which is perfect because ...` のように独立して始めることがある。書き言葉の作問では、コンマでつながる形を扱う。

## 例

- 正例: `He said he had finished the report, which turned out to be untrue.`(「報告書を終えたと言ったこと」全体を受ける)
- 正例: `She just lives six doors away, which is very handy.`
- 対比例: `He gave me a report which was untrue.`(`which` が名詞 `a report` を先行詞にする制限用法)

## 誤りやすい説明

- 非制限用法の `that` で置き換えられる、とは述べない。
- `what` を「前の節を受ける関係詞」として説明しない。`what` は先行詞を含む名詞節を作る。
- 代名詞 `it` に置き換えられる、とは述べない。接続詞がないまま2つの節をつなぐことはできない。
- 節全体を受ける `which` を、常に直前の名詞を指すものとして訳さない。

## 問題・解説への反映

- 空所補充では、コンマの直後に置かれ、後続の述語の主語になっていることを手がかりにさせる。
- 誤答には、非制限用法で使えない `that`、先行詞を含む `what`、接続詞を欠く `it` を用意する。
- 名詞を先行詞にする用法との違いは [関係代名詞の制限用法・非制限用法](./relative-clause-uses.md) と合わせて参照する。
