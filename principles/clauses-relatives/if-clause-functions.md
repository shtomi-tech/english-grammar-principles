# if節の働きと意味

## 原則

`if` は、節全体の文中での働きによって意味が変わる。

1. 副詞節を導く場合は、条件を表す「もし～ならば」となる。
2. `even if` の形で副詞節を導く場合は、「たとえ～でも」となる。
3. 名詞節を導く場合は、「～かどうか」となる。

## 判断条件

- `if` が導く節全体が、主節の条件を表す副詞節か、文の要素になる名詞節か確認する。
- `even if` か単独の `if` か確認する。
- 名詞節の `if` は、疑問の内容「～かどうか」として文中に組み込まれているか確認する。

## 適用範囲・例外

ここでは、`if` と `even if` が導く副詞節、および「～かどうか」を表す名詞節を扱う。仮定法の公式や、時・条件を表す副詞節内の時制は、それぞれの原則と合わせて確認する。

## 例

- 副詞節: `If it rains, we will stay home.` — 「もし雨が降れば、家にいる」。
- `even if`: `Even if it rains, we will go.` — 「たとえ雨が降っても、行く」。
- 名詞節: `I don't know if it will rain.` — `if it will rain` が「雨が降るかどうか」という名詞節。

## 誤りやすい説明

- `if` が導く節を、いつも条件の副詞節だと考えない。
- 単独の `if` と `even if` を区別せず、いつでも「たとえ～でも」と訳さない。
- 名詞節の `if` を、主節に条件を付ける副詞節として扱わない。

## 問題・解説への反映

- `if` の意味を問うときは、節全体の働きと `even` の有無を確認させる。
- 解説では、副詞節なら条件、名詞節なら「～かどうか」と明記する。
- 時・条件の副詞節の問題では、`egp.tense-aspect.adverb-clause-present-for-future` と必要に応じて併記する。
