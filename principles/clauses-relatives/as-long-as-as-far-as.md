# as long as と as far as の使い分け

## 原則

置き換えられる日本語の範囲によって、`as long as` と `as far as` を使い分ける。

- 「～する時間内では」と置き換えられる場合は `as long as` を使う。
- 「～する範囲内では」と置き換えられる場合は `as far as` を使う。

## 判断条件

- 表したいのが時間の長さ・期間か、知識・認識などの範囲か確認する。
- 「～する時間内では」に置き換えて自然なら `as long as` を選ぶ。
- 「～する範囲内では」に置き換えて自然なら `as far as` を選ぶ。

## 適用範囲・例外

ここでは、時間の `as long as` と範囲の `as far as` を対比する。条件を表す `as long as`（「～する限り」）など、別の用法はこのカードだけで判断しない。

## 例

- 時間: `You can stay here as long as you need.` — 「必要な時間内は、ここにいてよい」。
- 範囲: `As far as I know, the store is closed.` — 「私の知る範囲では、その店は閉まっている」。
- 範囲: `As far as the eye can see, there were fields.` — 「見渡せる範囲では、野原が広がっていた」。

## 誤りやすい説明

- `long` と `far` の語感だけで決めず、時間か範囲かを確認する。
- `as long as` をすべて時間の意味、`as far as` をすべて距離の意味と決めつけない。
- 条件の `as long as` と、時間を表す `as long as` を区別しないまま同じ説明にしない。

## 問題・解説への反映

- 空所問題では、節が表す内容を時間か範囲かに言い換えてから正答を判定する。
- 解説では、選んだ表現が時間・範囲のどちらを表すかを明記する。
- 条件の `as long as` を扱う場合は、このカードの時間用法と区別して説明する。
