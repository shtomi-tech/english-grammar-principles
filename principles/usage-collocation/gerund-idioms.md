# 動名詞を使った慣用表現

## 原則

`used to + 動詞の原形`は「以前は〜していた(今はしていない)」という過去の習慣・状態を表す。これに対し`be used to + 動名詞/名詞`は「〜に慣れている(状態)」、`get used to + 動名詞/名詞`は「〜に慣れる(変化・プロセス)」を表し、いずれも動名詞を伴う点で`used to`と形が異なる。`cannot help + 動名詞`は「〜せずにはいられない」(=`cannot help but + 動詞の原形`)、`be worth + 動名詞`は「〜する価値がある」を表す。

## 判断条件

- 過去の習慣(used to do)か、現在の慣れた状態(be used to -ing)か、慣れていく変化(get used to -ing)かを確認する。
- 動詞の原形が続くか、動名詞が続くかで`used to`と`be/get used to`を区別する。

## 適用範囲・例外

- `be used to`の`used`は形容詞的に働き、`used to`(過去の習慣)の`used`とは品詞が異なる。
- 本カードは`be/get used to + 動名詞`(慣れ)の側を扱う。`used to + 原形`(過去の習慣・状態)そのものの判断、および`would`との使い分けは[used to + 原形(過去の習慣・状態)](../modality/used-to.md)を正本とする。
- `cannot help but + 動詞の原形`は`cannot help -ing`よりやや形式的な言い換えである。

## 例

- 正例: `I used to get up early.`(以前は早起きしていた)
- 正例: `I am used to getting up early now.`(今は早起きに慣れている)
- 正例: `I am getting used to getting up early.`(早起きに慣れてきている)
- 正例: `I couldn't help laughing at the joke.`
- 正例: `This book is worth reading.`

## 誤りやすい説明

- `used to`と`be used to`を「toの後ろは常に原形」と一括りにしない。前者は原形、後者は動名詞である。
- `worth`を`worth to do`のように不定詞と結び付けない。`worth`の後ろは動名詞である。

## 問題・解説への反映

- 空所直後の形(原形か動名詞か)を手がかりに、`used to`と`be/get used to`を区別させる。
- `cannot help`と`worth`は、後ろに動名詞が続く慣用表現として、不定詞を選ぶ誤答と対比させる。
