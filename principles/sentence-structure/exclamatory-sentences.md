# 感嘆文(What/How)の形

## 原則

感嘆文は驚きや強い感情を表す文で、`What (a/an) + 形容詞 + 名詞 + S + V!`または`How + 形容詞/副詞 + S + V!`の形を取る。`What`は後ろに名詞(を含む句)を、`How`は後ろに形容詞または副詞のみを続け、名詞を直接続けない点で区別する。文末の`S+V`は省略されることも多い。

## 判断条件

- 感嘆の対象が名詞句(a beautiful flower)か、形容詞・副詞単体(beautiful/fast)かを確認する。

## 適用範囲・例外

- 名詞が可算名詞単数のときは`a/an`を伴う(`What a beautiful flower!`)。不可算名詞・複数名詞では`a/an`を付けない。

## 例

- 正例: `What a beautiful flower this is!`
- 正例: `How beautiful this flower is!`
- 対比例: `How a beautiful flower this is!`(誤り。Howの後ろに名詞は続けない)

## 誤りやすい説明

- `What`と`How`を「同じ意味で交換できる」と説明しない。後続要素の品詞(名詞か形容詞・副詞か)で機械的に決まる。
- 感嘆文を疑問文と混同し、`What`の後ろを疑問文の語順(倒置)にしない。

## 問題・解説への反映

- 空所の直後が名詞句か形容詞・副詞かを手がかりに、What/Howを判断させる。
- 誤答には、a/anの付け忘れやHowの後ろに名詞を置く誤りを含める。
