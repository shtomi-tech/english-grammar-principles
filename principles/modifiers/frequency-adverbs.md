# 頻度の副詞

## 原則

頻度の副詞は、動作や状態がどの程度の頻度で起こるかを表す。次の数値は厳密な確率ではなく、学習上の目安である。

| 目安 | 語 | 意味 |
|---:|---|---|
| 100% | `always` | いつも |
| 80% | `usually / generally` | たいてい |
| 60% | `often / frequently` | しばしば |
| 50% | `sometimes` | ときどき |
| 20% | `occasionally` | ときたま |
| 10% | `seldom / rarely` | めったに～ない |
| 5% | `hardly ever / scarcely ever` | ほとんど～ない |
| 0% | `not / never` | いっさい～ない |

## 判断条件

- 動作や状態が起こる頻度をどの程度として述べているか確認する。
- 数値は暗記上の目安として使い、文脈上の頻度を優先する。

## 適用範囲・例外

この一覧では、`not / never` を0%の目安として並べる。`not` は否定を表す語であり、厳密な意味での頻度副詞かどうかは文中の働きとともに確認する。

このカードは頻度の強さのみを扱う。文中の語順（一般動詞の前、be動詞の後ろ、助動詞・完了形の後ろ）は [[frequency-adverb-position]] を参照する。

## 例

- `She usually walks to school.`: 通学することがたいてい起こる。
- `He never eats breakfast.`: 朝食を食べることが0%の目安である。

## 誤りやすい説明

- パーセントを数学的な確率として正答判定に使わない。
- 頻度の副詞の位置は語によって異なるため、数値だけで語順を決めない。語順そのものは [[frequency-adverb-position]] の判断条件に従う。

## 問題・解説への反映

- 頻度表現の問題では、意味の強さと文脈を照合する。
- 解説では、数値を「記憶上の目安」として示し、厳密な割合だと説明しない。
