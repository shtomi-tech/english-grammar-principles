# 未来の仮定法の公式

## 原則

未来の仮定法には、次の2つの公式がある。

1. `If S + should + 原形, S + would + 原形 / 命令文 / 直接法`
   - 「もし（万一）～なら、…だろうに・…しなさい」
2. `If S + were to + 原形, S + would + 原形`
   - 「（あくまで仮の話で）～なら、…だろうに」

## 判断条件

- `if` 節が `should + 原形` か `were to + 原形` になっているか確認する。
- `should` の公式では、主節が `would + 原形`、命令文、または直接法のいずれかになっているか確認する。
- `were to` の公式では、主節が `would + 原形` になっているか確認する。

## 適用範囲・例外

このカードでは、未来について可能性を低く見積もる仮定、またはあくまで仮の話をする公式を扱う。`if` 節の `should` は、義務・忠告の `should` と区別する。

## 例

- `If you should need help, call me.`: もし万一助けが必要なら、私に電話しなさい。
- `If the plan were to fail, we would need a new one.`: もしその計画が失敗するとしたら、新しいものが必要だろうに。

## 誤りやすい説明

- `if` 節の `should` を、常に「～すべきだ」と訳さない。
- `were to` を、通常の未来の予定を表す形として扱わない。
- 未来の仮定法を、仮定法過去・仮定法過去完了と時点を区別せずに扱わない。

## 問題・解説への反映

- `should + 原形` と `were to + 原形` の形、意味、主節の種類をまとめて確認する。
- `should` の問題では、義務・推量・未来の仮定のどれかを構造と文脈で判定する。
