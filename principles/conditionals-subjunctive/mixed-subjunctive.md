# ミックス仮定法の公式

## 原則

ミックス仮定法は、次の公式で表す。

`If S + had + p.p., S + would + 原形`

意味は「もし（あのとき）～だったら、（今は）…だろうに」である。主節の `would` は、`could`・`might`・`should` に置き換えることもできる。

## 判断条件

- `if` 節が `had + p.p.` になっているか確認する。
- 主節が `would / could / might / should + 原形` になっているか確認する。
- 条件は過去、結果は現在の状態・可能性として読めるか確認する。

## 適用範囲・例外

このカードでは、過去の条件と現在の結果を組み合わせる公式を扱う。過去の結果を述べる `would have p.p.` とは、主節の形と時点を区別する。

## 例

- `If I had taken the job, I would live in Tokyo now.`: あのときその仕事を受けていたら、今は東京に住んでいるだろうに。

## 誤りやすい説明

- `If S had p.p.` があれば、必ず過去の結果になると決めつけない。
- 主節が `would + 原形` なのに、結果を必ず過去の出来事として訳さない。

## 問題・解説への反映

- ミックス仮定法の問題では、条件の時点と結果の時点を分けて確認する。
- `would have p.p.` を選ぶ過去完了仮定法との違いを、主節の形と意味で説明する。
