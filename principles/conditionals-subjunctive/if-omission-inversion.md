# If省略による倒置

## 原則

仮定法では、`if` を省略し、省略の目印として倒置を起こすことができる。主語の前に動詞を出す、簡略な倒置が使えるのは `Were`・`Had`・`Should` の場合である。

## 判断条件

- 仮定法の `if` が省略されているか確認する。
- 文頭が `Were + S`、`Had + S`、`Should + S` の形になっているか確認する。
- 倒置を元に戻して、`if` を補って意味が通るか確認する。

## 適用範囲・例外

このカードでは、仮定法の `if` 省略に伴う倒置を扱う。一般の疑問文の倒置や、`Were / Had / Should` 以外の動詞を前に出す倒置は、このカードの対象にしない。

## 例

- `Had I known, I would have helped.` = `If I had known, I would have helped.`
- `Were I you, I would accept.` = `If I were you, I would accept.`
- `Should you need help, call me.` = `If you should need help, call me.`

## 誤りやすい説明

- `if` を省略すれば、どの仮定文でも自由に倒置できるとは限らない。
- 疑問文の倒置と、仮定法の `if` 省略による倒置を混同しない。

## 問題・解説への反映

- 倒置された仮定文では、文頭の `Were / Had / Should` を手がかりに元の `if` 節を復元する。
- `were`、`had`、`should` のどの公式に対応するかを確認して解説する。
